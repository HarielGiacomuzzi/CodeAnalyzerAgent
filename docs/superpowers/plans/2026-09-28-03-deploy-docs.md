# Code Analyzer Agent — Plan 3 of 3: Deployment, Samples, Docs and Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the app deployable to Railway, testable against real sample code, fully documented (root `README.md` + `docs/`), and pushed to `origin/main`.

**Architecture:** One Docker image (uv-installed deps, `uvicorn main:app`) described by `railway.json`, health-checked on `/health`. `samples/` holds deliberately flawed files; `scripts/smoke.py` (stdlib only) posts each sample to a running instance — local or deployed — and validates the response shape. Docs live in `README.md` (entry point) and `docs/` (API, architecture, prompts, deployment).

**Tech Stack:** Docker, Railway, uv, Python stdlib (`urllib`), Markdown.

**Spec:** `requirements.md` (repo root). Depends on Plans 1 and 2 (`docs/superpowers/plans/2026-09-28-01-backend-api.md`, `docs/superpowers/plans/2026-09-28-02-frontend.md`) being complete.

## Global Constraints

- Deploy target: Railway. Container listens on `$PORT` (default 8000). Health check path `/health`.
- Required env var: `ANTHROPIC_API_KEY`. Optional: `ANTHROPIC_MODEL` (default `claude-opus-5`).
- Deliverables to document: working API, custom system prompt, structured JSON output, 2+ analysis types (general, security, performance), deployment, sample-code testing, web frontend, deployed URL.
- Root `README.md` must be clear and complete; `docs/` must be complete. No new runtime dependencies.
- Commit directly on `main`, then `git push origin main`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never commit secrets: `.env` stays git-ignored; only `.env.example` is committed.

## Review Focus

- **Railway injects `PORT`:** the container must bind `0.0.0.0:$PORT`, not a hard-coded 8000, or the deploy health check fails.
- **Deploy without `ANTHROPIC_API_KEY`:** health check must still pass (Plan 1 guarantees `/health` is 200) so the service comes up and `/analyze` explains the missing key; the deployment doc must say to set the variable.
- **Smoke script against a server that returns errors:** it must exit non-zero and print the HTTP status and `detail`, not crash with a traceback.
- **Docs drifting from code:** every endpoint, field, env var and command in the docs must match the code as built in Plans 1-2 (reviewer diffs `docs/API.md` against `analyzer/models.py` and `main.py`).
- **Public endpoint cost exposure:** docs must state that `/analyze` is unauthenticated and spends API credits, and name the mitigation (Railway private networking / spend limit on the Anthropic key).

- [ ] **Step 3: Create `scripts/smoke.py`**

```python
"""End-to-end smoke test: analyze every file in samples/ against a running instance.

Usage: uv run python scripts/smoke.py [BASE_URL]   (default http://localhost:8000)
Exits 1 if the service is unhealthy or any analysis fails validation.
"""

import json
import sys
import urllib.error
import urllib.request
from pathlib import Path

BASE_URL = (sys.argv[1] if len(sys.argv) > 1 else "http://localhost:8000").rstrip("/")
SAMPLES = {
    "insecure_app.py": ("python", "security"),
    "slow_report.py": ("python", "performance"),
    "buggy_cart.js": ("auto", "general"),
    "clean_utils.py": ("python", "general"),
}
REQUIRED = {"language", "summary", "issues", "suggestions", "metrics", "analysis_type", "stats"}


def call(method: str, path: str, payload: dict | None = None) -> tuple[int, dict]:
    data = json.dumps(payload).encode() if payload is not None else None
    req = urllib.request.Request(f"{BASE_URL}{path}", data=data, method=method, headers={"Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(req, timeout=300) as res:
            return res.status, json.load(res)
    except urllib.error.HTTPError as exc:
        return exc.code, json.loads(exc.read() or b"{}")
    except (urllib.error.URLError, TimeoutError) as exc:
        return 0, {"detail": str(exc)}


def main() -> int:
    status, health = call("GET", "/health")
    print(f"GET /health -> {status} {health}")
    if status != 200:
        return 1

    failures = 0
    for name, (language, analysis_type) in SAMPLES.items():
        code = (Path(__file__).parent.parent / "samples" / name).read_text()
        status, body = call("POST", "/analyze", {"code": code, "language": language, "analysis_type": analysis_type})
        missing = REQUIRED - body.keys()
        if status != 200 or missing:
            failures += 1
            print(f"FAIL {name}: HTTP {status} detail={body.get('detail')} missing={sorted(missing)}")
            continue
        print(f"OK   {name} [{analysis_type}] language={body['language']} issues={len(body['issues'])} metrics={body['metrics']}")
        print(f"     summary: {body['summary']}")
        for issue in body["issues"]:
            print(f"     - {issue['severity']:<8} line {issue['line']}: [{issue['category']}] {issue['description']}")
    return 1 if failures else 0


if __name__ == "__main__":
    sys.exit(main())
```
